## Базовые спецификаторы

- `%c` — вывод одного символа (`char`).
- `%s` — вывод строки (указатель на `char`, до первого `\0`).
- `%d` или `%i` — десятичное знаковое целое (`int`).
- `%u` — десятичное беззнаковое целое (`unsigned int`).
- `%o` — восьмеричное представление беззнакового целого.
- `%x` / `%X` — шестнадцатеричное представление (`x` — строчные буквы a–f, `X` — заглавные).
- `%f` — число с плавающей точкой в десятичном виде (`double`; `float` тоже передаётся как `double`).
- `%e` / `%E` — экспоненциальная запись (`e` — строчная `e`, `E` — заглавная).
- `%g` / `%G` — автоматический выбор между `%f` и `%e` (или `%E`) — оставляет меньше лишних нулей.
- `%%` — выводит сам символ `%`.

---

## Модификаторы длины (префиксы перед типом)

Они уточняют размер типа и важны, чтобы корректно печатать `short`, `long`, `long long` и т. д.:

- `hh` — для `signed char` / `unsigned char` (например, `%hhd`, `%hhu`).
- `h` — для `short` / `unsigned short` (например, `%hd`, `%hu`).
- `l` — для `long` / `unsigned long` (например, `%ld`, `%lu`). Для `%s`, `%c` тоже допустимо, но обычно не нужно.
- `ll` — для `long long` / `unsigned long long` (например, `%lld`, `%llu`).
- `L` — для `long double` (например, `%Lf`, `%Le`, `%Lg`).

> Пример: `printf("%lld", x);` — корректно для `long long`.

---

## Флаги и ширина/точность (внутри формата)

Это не отдельные спецификаторы, а части формата, которые часто используют вместе с ними:

- `-` — выравнивание по левому краю.
- `+` — всегда выводить знак (`+` или `-`).
- Пробел — пробел перед положительным числом (если нет `+`).
- `#` — альтернативная форма: у `%o` добавляет ведущий `0`, у `%x`/`%X` добавляет `0x`/`0X`, у вещественных чисел всегда показывает десятичную точку.
- `0` — дополнение нулями слева (работает с числовыми типами).
- _ширина_ (число) — минимальная ширина поля.
- `.точность` — для целых: минимальное число цифр (дополняется нулями), для вещественных — число знаков после запятой, для строк — максимальная длина.

Примеры:

- `%5d` — число минимум в 5 символах (по умолчанию справа).
- `%-5d` — то же, но выровнено влево.
- `%05d` — дополняет нулями до 5 символов.
- `%.2f` — ровно 2 знака после запятой.
- `%10.2f` — общая ширина 10 символов, 2 после запятой.
